# next-level-program

A documented 9-month program taking a Senior Azure Engineer to Cloud/AI Architect: multi-cloud (Azure, AWS, GCP), Terraform/Python/Kubernetes, FinOps, and the executive skills to present it.

- `ROADMAP.md` — the plan: phases, gates, curriculum, resources (exported from the working doc)
- `resources.md` — every book, course, and video, rated 1–5 with one line on who it's for
- `retros/` — monthly retrospectives (kept / changed / dropped)
- `briefs/` — the best of the weekly one-page briefs, once polished
- `talks/` — links and notes for recorded and delivered talks

Phase gates:
1. Jan 24, 2027 — Terraform Associate, AWS SAA, FinOps Practitioner; multi-cloud Terraform repo; cost CLI; cost case study
2. Apr 25, 2027 — two capstones published; CKA; FinOps Engineer; GCP ACE
3. Jul 23, 2027 — signed offer; GCP PCA
